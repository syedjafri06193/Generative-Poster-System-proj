# Press profiles

`FOGRA39L_coated.icc` is the FOGRA39L (ISO 12647-2:2004, coated paper) characterisation. It comes from the TeX Live distribution, where it is listed as free of known copyright restrictions. It is embedded as the PDF/X-4 output intent.

To add another printing condition, put its ICC file here and add a `PressProfile` to `PRESS_PROFILES` in `src/model/press.ts`.
